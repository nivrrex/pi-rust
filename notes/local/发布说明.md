# pi-rs 发布说明

**版本：`v0.87.1`（首次公开发布）**
- 二进制自报：`pi-rs 0.87.1`，`built <时间> commit <HEAD 短号>`
- 行为规格：上游 pi **0.87.1**（`ref/pi-0.87.1/`，commit `f07218c`）
- 与上游的会话文件、`settings.json`、`models.json`、`auth.json` **双向互通**

## 已实现

- **四种模式**：TUI（默认）、`-p/--print`、`--mode json`、`--mode rpc`；`-c` 续写会话
- **provider api**：`openai-completions`、`openai-responses`、`anthropic-messages`
  （TLS 走 rustls，无 OpenSSL）
- **TUI**：差分渲染、编辑器（行编辑/补全/大段粘贴折叠）、`/model` `/settings` `/tree`
  `/resume` `/thinking` `/scoped-models` `/session` `/hotkeys` `/trust` `/reload`
  `/changelog` `/compact` `/copy` `/name` `/clone` `/fork` `/import` `/export`(jsonl) `/new`；
  `/resume` 支持重命名与删除
- **会话条目**：`message`、`session_info`、`branch_summary`（`/tree` 导航含摘要与无摘要）、
  `compaction`、`model_change`、`thinking_level_change`、`context_edit`、`custom_message`；
  未知类型原样往返，读后写回不丢字段
- **扩展（extension，需本机有 `node`）**：宿主协议、工具/命令/事件注册、`ctx.ui`
  （notify / 工作消息 / 工具展开 / 页脚）、Markdown 变换器、`pi.events` 总线、
  `project_trust` 与 `session_before_tree` 事件；`.ts` 扩展所需 jiti 的 shim 已内嵌
- **键位**：`keybindings.json` 生效（旧键名迁移、冲突检测），`/hotkeys` 面板跟随配置
- **Windows**：额外提供 `powershell` 工具（不在默认集，`--tools powershell` 启用）

## 未实现（明确报错，不假装成功）

- 内置斜杠命令 `/share`（需 GitHub gist）、`/bug`（上传/导出 zip）
- `/export` 的 **HTML** 分支（`.jsonl` 已支持；HTML 明确报错且不写文件）
- 扩展 `ctx`/`ctx.ui`/`pi` 的 14 个成员、10 个扩展事件（已装扩展均未使用）
- `/login` 的 OAuth 型 provider（明确提示不支持）
- `/changelog` 的 Extensions 快捷键段、窗口缩放重排
- 部分 TUI 场景的样式层仍有 1–9 格差异（多为启动屏 `bold`/`dim`）；文本层已一致
- Windows 为**实验性**：交叉编译 + 有限真机验证

## 回退方式（保留原版 pi）

本版**不覆盖、不修改**已安装的上游 `pi`，两者可并存：

1. **配置与会话共用**：本版读同一份 `settings.json`/`models.json`/`auth.json` 与会话目录，
   写入仍是同一格式（已双向验证）⇒ 随时可切回 `pi`，无需迁移。
2. **切回原版**：直接运行原来的 `pi` 命令。若 PATH 里 `pi-rs` 排在前面，用完整路径
   或调整 PATH 顺序即可。
3. **删除本版**：删掉 `pi-rs` 二进制即可；它不写系统目录、不安装服务
   （Devuan 5 / sysvinit 环境无需卸载步骤）。
