# F36 真机清单

## Linux x86 / arm（Alacritty / WezTerm / kitty）
1. 启动 TUI → `Ctrl+D` 退出 → 在 shell 里按 **↑**：应正常取回历史，**不得出现** `^[[A` 或 `0;5:3u`。
   （F36/H1 修的是退出时没复位 modifyOtherKeys。）
2. 输入 `/`、`/to`：补全菜单应列出扩展开命令（含描述）；`/todo` 能打开 todo 清单。
3. Todo 面板（`pi-handoff-gate`）：`setWidget` 的 belowEditor 面板出现在编辑器下边框**之下**、底栏**之上**，
   每行带 1 列缩进；清单清空后面板消失。
4. 底栏：`↑n ↓n R… W… CH…% x.x%/Nk (auto) … (provider) model • level`；
   带缓存用量的会话里 `R/W/CH` 三段的数值与 `/session` 一致。
5. 工具行摘要（H4 未实现，当前走原生渲染）：`pi-ai-summary` 若启用，工具行应仍完整显示参数与结果；
   若出现 `[PI_AI_SUMMARY_INSTALL_FAILED]` 记下原文。

## Windows
1. `pi-rs` 启动：`[Extensions]` 正常列出；退出时**不得**打印 Node 堆栈（F36/H6a 修的是 socket RST 静默退出）。
2. 退出后**不重复**渲染页脚（若观察到重复，记录发生时机与终端的换行行为）。
3. 只有 `!` 命令的会话退出后不产生会话文件、不打印 `To resume this session`。
