# F39 真机清单（Alacritty）

开始前先确认没有残留：`pgrep -af 'pi-rs|runner.mjs'` 应为空。

## 一、退出后立刻按上键（M2 主项）
1. 启动 `pi-rs` → `Ctrl+D` 退出 → **立刻**（不等提示符）按 ↑：
   预期取回上一条历史；**不得**出现字面 `^[[A`。
2. 若仍出现：连按空回车一次后是否恢复；再回报 `pgrep -af 'runner.mjs'` 的输出。
3. 数据：退出收尾（最后一次写 tty → 进程返回）已从 161 ms 降到 60 ms（TS 40 ms），
   drain idle 由 150 ms 改为 ref 的 50 ms。

## 二、粘贴一行命令（M2 关联）
退出后立刻粘贴一行命令（Ctrl+Shift+V）：预期只出现一次命令文本，**不得**看到字面
`^[[200~` / `^[[201~`（bracketed paste 未复位时的典型症状）。

## 三、斜杠菜单与 Todo 部件（M0）
1. `/` 菜单应列出内置命令 + 扩展开命令（扩展开带 `[u]` 前缀与描述）。
2. `/todo` 打开清单后，Todo 面板在编辑器下边框之下、底栏之上：
   ` Todo ▱▱▱▱ 0/3` / ` ▶ #1 …` / ` · #2 …`。
3. 工具行：真实 `pi-ai-summary` 的折叠行（`✓ name {args} · 0.0s`）**当前仍不生效**——
   它是扩展对 `ToolExecutionComponent.prototype` 的打补丁，跨进程架构下无法作用于 Rust 渲染，
   已在 `notes/p9-f39/plan.md` 登记为待单列批次。若看到的是内置展开渲染，属已知差异。

## 四、Windows
退出时不得打印 Node 堆栈；不得重复渲染页脚。
