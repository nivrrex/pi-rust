# F38 真机清单

## 一、Alacritty 退出后方向键（K1）
1. `pi-rs` 里 `Ctrl+D` 退出 → 按 ↑：应正常取回历史。
2. 若仍异常，回报三条：`printf '\e[?u' | cat -v`（kitty flags 是否非 0）、
   `stty -a | grep -o -- '-\?icanon'`、`cat -v` 后按 ↑ 显示 `^[[A` 还是 `^[OA`。
3. 已知结论：pty 三配置（无应答 / Alacritty 式 / xterm 式）下，pi-rs 退出后**无遗留模式**、
   tty 输入队列**零残留**（TS 在 100ms 应答延迟下残留 12 字节）。

## 二、Ctrl+C 双击（K1e）
编辑器为空时 500ms 内连按两次 Ctrl+C 应退出（间隔更久只清编辑器）。已按 ref 实现并有单测。

## 三、斜杠菜单与 Todo 部件（K3）
1. `/` 菜单应同时列出内置命令与**扩展注册的命令**，扩展项带 `[u]` 前缀与描述（用户级扩展）。
2. `/todo` 应打开清单；Todo 面板在编辑器下边框之下、底栏之上，字符串数组形态每行 1 列缩进。

## 四、工具行摘要（K4）
1. `pi-ai-summary` 启用时，工具行/页脚应**随状态刷新**（用量、模型、回合推进）。
2. 若扩展渲染抛错，应看到 `[Extension issues]` 里一条"渲染失败，已回落内置渲染"，且界面不空白。

## 五、Windows
1. 退出时不得打印 Node 堆栈（H6a）；不得重复渲染页脚（K2 在 Linux 未复现）。
2. 只有 `!` 命令的会话不产生会话文件、不打印 `To resume this session`。
