---
name: visual-summary
description: >-
  把一份完整材料（对话、Word/PDF/PPT/Excel/Markdown/txt）的精华压缩成一张可直接分享的静态海报 PNG。
  当用户说"总结成一张图/一张海报/一页看懂/一眼看懂这份报告/把这份材料做成海报/一图总结/信息图总结/
  visual summary/poster summary"，或想把长文档、会议记录、课程、报告压成单页视觉摘要时使用。
  输出为单张 PNG（默认竖版 1200×1600）并保留 HTML 源文件。
  边界：本 skill 的产出是单张静态海报文件——多页/可交互报告、幻灯片、对话中的临时示意图、
  纯设计海报（传单/邀请函，没有需要总结的材料）均不适用。
  本 skill 只做一件事：整份材料 → 一张图。
---
