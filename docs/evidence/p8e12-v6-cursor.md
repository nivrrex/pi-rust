# V6（Linux 侧同口径录制）：光标行列对拍

## 方法
`tmux` 100×30，两侧都读 **tmux 的 `#{cursor_x},#{cursor_y}`**（同一测量口径），
用 `tmux paste-buffer -p` 注入真实括号粘贴 12 行，然后逐个按键并记录坐标。

## 结果（12 行粘贴后）
| 动作 | TS | pi-rs | 判定 |
|---|---|---|---|
| 粘贴后 | `20,17` | `20,21` | **行号差 4**（列一致） |
| Up | `0,17` | `0,21` | 列一致（都跳到行首） |
| Down | `20,17` | `20,21` | 列一致 |
| Left ×3 | `0,17` | `0,21` | 一致 |
| Home | `0,17` | `0,21` | 一致 |
| End | `20,17` | `20,21` | 一致 |
| 输入 `中文测试` | `28,17` | `28,21` | 列一致（4 个全角 = 8 列） |
| 退格 ×2 | `24,17` | `24,21` | 一致 |

结论：**列与按键语义已经对齐**；差异只剩"编辑器在屏幕上的垂直位置"（行号整体差 4）。

## 本轮据此修的两处真偏差
1. **`Home`/`End` 序列缺失**：`tmux send-keys Home` 实际发的是 `ESC[1~`、`End` 是 `ESC[4~`
   （`od -c` 取证），我们原来只认 `ESC[H`/`ESC[F` ⇒ End 键完全无效。已按 ref
   `keys.ts:373-374` 补上 `[1~`/`[7~`/`[4~`/`[8~`。
   > 附带更正：oracle 夹具原先把这两项记成 `key=null`，与 ref 源码和实测都不符，
   > 已同步改正（`fixtures-input.lines.txt` + `.json`），理由写进夹具的 `note`。
2. **↑/↓ 的行内跳转**（ref `editor.ts:922-948`）：已在首行且光标不在列 0 ⇒ 跳到行首；
   已在末行且不在行尾 ⇒ 跳到行尾；只有空编辑器 / 正在浏览历史 / 列已为 0 才翻历史。
   修前 `Up` 在单行粘贴上毫无反应（`20,21` 不动），修后与 TS 一致（`0,21`）。
