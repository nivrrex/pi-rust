# F52 真机复测清单（E1–E5）

前置：`cargo build --release` 后用 `target/release/pi-rs`；会话目录/配置目录自定，别用默认 `~/.pi`（有真实凭据）。

## E1 展开（`ctrl+o`）后超长 bash 头行

1. 让模型跑一条同时含 `timeout: 600`、多行命令、超长单行的 bash（例如 heredoc + `seq 1 60` 拼一条长路径）。
2. 按 `ctrl+o`（状态行应变 `Tool output: expanded`）。
3. 预期：头部命令**按行拆开**（不折成一坨）、每行都有 1 列前导空格、超宽部分**折行**而不是被截断；
   末行 ` (timeout 600s)` 必须完整可见（F52/C 已改：`text.ts:60-68` 的 tab→3 空格 + 按 `\n` 拆行 + 折行）。

## E2 命令含换行（heredoc）时的缩进

1. 同上一条的 heredoc 命令。
2. 预期：` $ cat <<'EOF' …`、` 第一行…`、`    缩进行 with tab`（tab→3 空格 + 1 列 padding）、` EOF` 逐行左对齐，
   没有"阶梯缩进"（旧 bug：整个多行命令挤成一行后被裁）。

## E3 `ctrl+o` 双向（有扩展折叠工具行时）

前提：装 `pi-ai-summary`（或任何给 `ToolExecutionComponent.render` 打补丁的扩展）。

1. 默认折叠态：工具行是一行摘要（如 `+ bash … · ok`）。
2. 按 `ctrl+o`：**应变成原生块**（头部 + 输出 + ` Took …`），不再是折叠行，也不再有
   `... (N earlier lines, ctrl+o to expand)` 预览提示（`ttools_expanded` 走原生全文）。
3. 再按 `ctrl+o`：**应回到折叠行**（F52/A 修的第二个 bug：展开态那一批整批返回 null 曾把请求永久停用）。

## E4 `ctrl+t` 思考块可见性

1. `settings.json` 里 `hideThinkingBlock: true` 起会话，跑一次带思考的回合。
2. 屏上应只有一行标签：扩展给了标签时是 ` + Thought: …`（带 1 列前导空格），否则 ` Thinking...`。
3. 按 `ctrl+t`：状态行 `Thinking blocks: visible`，思考块**显示全文**（旧 bug：正文在恢复/渲染时被丢弃，只有标签）。
4. 再按 `ctrl+t`：回到标签行。标签在**两态来回**都要正确（缓存键里含 hide 标志与标签内容）。

## E5 恢复会话的底栏（分支名 / thinking 档 / 费用形态）

两条恢复路径**分开测**，结论应一致：

- `pi-rs --session <会话文件绝对路径>`
- `pi-rs -c`（在会话自己的 cwd 里执行；`-c` 按 ref 用进程 cwd，不从会话头取）

预期：
1. 左行 cwd 带分支名（如 `/root/Desktop/pi-rust (recover)`）。
   `--session` 时 cwd 取**会话头里的 cwd**（ref `session-manager.ts:1779`），`-c` 取进程 cwd。
2. 右行模型名后带 `• high`（会话里最后的 `thinking_level_change`）；非推理模型不显示档位。
3. 费用形态：原生页脚是 `$0.123`（三位小数，ref `footer.ts:146-149`）；扩展页脚（`pi-ai-summary`）是 `¥954.32`。
   两者可以同时出现，各自独立。
4. 退出后再看终端：会话结束提示行不得残留半截 ANSI（`\x1b[?2026h` 等）。
