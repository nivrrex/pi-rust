# F54 真机清单（Windows 专有项，可选复核，**不作完成条件**）

自动化（Devuan 5 + PTY + unix netns）无法覆盖以下项，须在 Windows 真机手验。
每条写明"预期"，出现偏差时按条登记，不计入批次完成判定。

1. **conhost VT 输入**
   - 现象面：Windows 控制台在 VT 输入模式下不把 `Ctrl+D`/`Ctrl+P` 变成可用字节，pi-rs
     为此在 `#[cfg(windows)]` 走 crossterm 事件（`crates/pi-cli/src/tui.rs:1589` 附近）。
   - 预期：`ctrl+d` 空编辑器退出、`ctrl+p` 切模型、`shift+ctrl+p` 反向切模型均生效；
     `Esc`/`Ctrl+C` 恢复正常。
   - 失败判据：按键无反应，或退出后 shell 里出现 `0;5:3u` 这类残留。

2. **路径大小写**
   - 现象面：`C:\Users\Admin` 与 `c:\users\admin` 在 Windows 等价，在 Linux 不等价。
   - 预期：`[Context]` 段的相对路径/家目录缩写与 TS 一致；会话头 cwd 与进程 cwd
     比较不因大小写产生差异（`--session` 用 header.cwd、`-c` 用进程 cwd，见
     `notes/decisions.md` 的对应条目）。
   - 失败判据：同一文件在 `[Context]` 出现两次，或 `--session` 恢复后 footer cwd 变空。

3. **Ctrl+D 语义**
   - 现象面：conhost 里 `\x04` 可能被行编辑层吞掉。
   - 预期：空编辑器按 `ctrl+d` 退出并打印 resume 行；非空时不清空。
   - 失败判据：按一次就退出（非空时）或完全不退出。

4. **`isTTY` 副作用**
   - 现象面：`process.stdout.isTTY` 在 conhost / Windows Terminal / mintty 下不同，
     TS 侧据此决定是否发 DA1、kitty、OSC 11 查询（`packages/tui/src/terminal.ts:174-191`）。
   - 预期：pi-rs 与 TS 在同一宿主下的启动查询集相同；不出现"等待应答超时"。
   - 失败判据：启动多等 1–2 秒才出首帧，或退出后终端停在 raw。

5. **窗口缩放（`SIGWINCH` 等价）**
   - 现象面：Windows 没有 `SIGWINCH`，crossterm 的 `Event::Resize` 是唯一来源。
   - 预期：拖动窗口改变宽度后，长输入行按新宽度重排、footer 左右两段按
     `footer.ts:198-223` 的"至少 2 列间隔"规则排版（F54/Z3 在 Linux 已对齐）。
   - 失败判据：缩放后输入区仍按旧宽度排版，或 footer 左右粘连。

验证方式（真机）：`pi-rs` 与 `pi` 各开一个窗口，同一份 settings/models 副本，
逐条对照上表的"预期"。任何一条不符，登记到本节下方，不阻塞本批完成。
