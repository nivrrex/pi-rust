name: show-me
description: >-
  当用户明确要求把当前话题中的某个具体内容、结构、流程、关系、架构、UI 层级、数据流或改动
  "画出来看"时使用；也可在不使用视觉表达会明显降低理解效率时使用。触发词包括：画图、图解、
  可视化、架构图、流程图、时序图、调用关系、数据流、结构图、关系图、对比结构图，以及
  visualize / diagram / show me。用户贴出已有的 Mermaid 或 draw.io 源想要重新表达（重画、
  画好看点、redraw）时也用本 skill。不用于对整个文档、文件或长对话做视觉总结——本 skill
  只针对当前话题中的具体内容点。
